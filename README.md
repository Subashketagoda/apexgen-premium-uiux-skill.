# ApexGen Premium UI/UX Skills

Two complementary agent skills for Google Antigravity.

## Skills

- **frontend-design** — upstream skill from [Anthropic Skills](https://github.com/anthropics/skills/tree/main/skills/frontend-design). Its original Apache License 2.0 is retained alongside the skill.
- **apexgen-premium-uiux** — custom ApexGen workflow skill, licensed separately under MIT.

## Install

Copy either skill folder into the target project's .agents/skills/ directory:

- .agents/skills/frontend-design/SKILL.md
- .agents/skills/apexgen-premium-uiux/SKILL.md

Then invoke the skill from Antigravity if supported, or explicitly ask the agent to use it.
